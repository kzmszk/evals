# 企画依頼書: 短編シリーズの企画コンテスト(SF / 異世界ファンタジー)

このドキュメントは、短編シリーズ企画コンテストで各参加者に共通で渡す依頼書である。あなた(企画者)はこの依頼書だけを前提に、独立して企画を作成すること。

## 依頼内容

**同じ舞台を共有して短編・中編をシリーズ化できる短編シリーズ**の企画を立ち上げ、見本となる短編を1本書き下ろすこと。

- ジャンルは **近未来AIモノ(SF)** か **異世界ファンタジー(魔法・剣と魔法・異世界転移などを含む広義のファンタジー)** のどちらかを選ぶ(両方の融合も可)。選んだ理由を一言添えること
- 参考イメージ: 『マーダーボット・ダイアリー』『葬送のフリーレン』のように、同一の世界観・主人公(または主人公群)でエピソードを積み重ねられる構造
- 独自の世界観を確立してヒット作となり、**漫画化・アニメ化・映画化**につながることを目指す

## 対象読者

- ときどきライトノベルを読む人、アニメが好きな人
- マニア向けの重厚長大な設定より、キャラクターと読み口の良さで引き込むこと。ただし読者を子ども扱いせず、世界観の芯は硬く作ること

## 成果物の形式

単一の Markdown ドキュメントとして提出する。構成・見出しは自由だが、少なくとも以下を含めること:

1. **シリーズコンセプト** — 一行ピッチ(ログライン)、シリーズタイトル案、何が新しいのか
2. **世界観設定** — 舞台、ルール(AI/魔法の仕組みと制約)、その世界観が物語を生み続ける理由
3. **キャラクター設定** — 主人公(と主要キャラ)の人物像、関係性、シリーズを通した変化の余地
4. **シリーズ展開案** — 1話完結と縦軸(シリーズ全体の大きな流れ)の設計、続編エピソードの種を複数
5. **見本短編1本** — 目安 6,000〜12,000字。シリーズ第1話として読者を掴む完成品であること(あらすじやプロットではなく本文)

## 制約

- 他参加者の企画・作品を参照することは禁止(この依頼書だけを入力とする)
- 成果物の中で自分のモデル名・開発元に言及したり、自分がAIであることを示す記述をしないこと(匿名評価を行うため)
- 言語は日本語

## 評価について

提出された企画は、別途事前に定めた評価基準に基づき採点される。配点は **AI評価 50点 + 人間による定性評価 50点** の合計100点。AI評価の観点は「世界観の独自性」「シリーズ化構造」「キャラクター」「見本短編の完成度」「ターゲット適合・メディアミックス適性」。設定資料の網羅性より、**読者が続きを読みたくなるか**が評価される。
