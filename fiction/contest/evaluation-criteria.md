# 評価基準: 短編シリーズ企画コンテスト(SF / 異世界ファンタジー)

fable5 / opus4.8 / gpt5.5 が独立に作成した企画を評価する。総合評価は **AI評価 50点 + 人間による定性評価 50点 = 100点**。本ドキュメントは応募作を一切見る前に fable5 が作成・確定したものである。

## 評価の公平性について

- AI評価者(fable5)は参加者でもあるため、評価時には企画を **A / B / C と匿名化**して提示し、どのモデルの成果物かを伏せる
- 匿名化コピーはモデル名・自己言及の機械的リークチェックを通過させてから評価者に渡す
- 各観点の採点には**企画本文からの引用を根拠として**示すこと(印象点の禁止)

## AI評価(50点満点)

### 1. 世界観の独自性と説得力 — 10点

- 一行ピッチの段階で「読んだことがない」と感じさせる新規性があるか。既存ヒット作(参考例として挙げたマーダーボット、フリーレンを含む)の焼き直しになっていないか
- AI/魔法の仕組みに**明確なルールと制約**があり、それが都合よく破られない設計か
- 世界観が単なる背景ではなく、**物語(事件・葛藤)を自動的に生み続ける装置**として機能しているか

### 2. シリーズ化の構造設計 — 10点

- 1話完結で読める「フォーマット」(毎話の型)が発明されているか。その型で10話・20話と量産できるか
- 1話完結の横軸と、シリーズ全体を貫く縦軸(謎・目的・変化)の両立が設計されているか
- 舞台を共有する必然性があるか(単に同じ世界というだけでなく、積み重ねが効いてくる構造か)
- 展開案のエピソードの種が具体的で、実際に書ける水準か

### 3. キャラクター — 10点

- 主人公に**独自の「声」**(視点・語り口・ものの見方)があるか。設定表ではなく見本短編の本文でそれが実証されているか
- 主要キャラ間の関係性に、シリーズを通して転がせる伸びしろがあるか
- 「この人の話をもっと読みたい」とキャラクター自体が牽引力になるか

### 4. 見本短編の完成度 — 15点

配点最大。企画書がどれほど立派でも、実作が読ませなければヒットしない。

- **冒頭の引き**: 最初の1ページで読者を掴むか
- **単体の満足度**: 第1話として起承転結が完結し、かつ続きへの引きがあるか
- **文章技術**: 描写・会話・テンポの質。ライトノベル読者が読みやすい文体か
- **設定の溶かし込み**: 世界観説明が講義・お説教にならず、物語の中で自然に立ち上がるか
- 指定分量(目安 6,000〜12,000字の本文)を満たしているか。プロットやあらすじで代用していないか

### 5. ターゲット適合とメディアミックス適性 — 5点

- 「ときどきラノベを読む・アニメ好き」層に刺さる要素(キャラの掛け合い、ビジュアルイメージの喚起力)があるか
- 漫画・アニメ・映画にしたときの画(え)が想像できるか(名場面になりうるシーン、キャラデザが立つ造形)

## 人間による定性評価(50点満点)

人間(評価オーナー)が実際に読んで採点する。観点の目安(配点は自由に運用してよい):

- **続きを読みたいか** — 20点: 第2話が出たら読むか。率直な牽引力
- **キャラクターの好感度** — 10点: 主人公・脇役に愛着が湧くか
- **世界観への没入** — 10点: 設定を「信じられた」か、覚めた瞬間がなかったか
- **映像化を観たいか** — 10点: アニメ化されたら観るか、人に薦めるか

## 評価手順

1. 全企画を匿名化(A/B/C)し、モデル名等のリークを機械的にチェックする
2. AI評価者は観点ごとに採点し、引用つきのスコアシート(評価レポート)を作成する
3. 総合所見として、各企画の最大の強み・最大の弱点・「実際に出版レーベルに持ち込むならどれか」を述べる
4. AI評価の結果は `fiction/contest/evaluation-report.md`(匿名ラベルのまま)に、匿名解除後の集計は `fiction/contest/results.md` にまとめる
5. 人間評価は後日 `results.md` に追記し、合計100点で最終順位を確定する
