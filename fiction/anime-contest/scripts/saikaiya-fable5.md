# 『毎晩世界が組み変わるので、再会屋はじめました』

## アバンタイトル

### ○1 大陸・超上空(夜)

眠る大陸を、神の視点で見下ろしている。
点々と灯る街の明かり。海沿いに湾曲する港町、山あいに身を寄せる村、蛇行する川、月光を照り返す麦畑。世界は静かで、あたたかく、なにひとつ変わったところのない夜——に、見える。

遠くで、鐘がひとつ鳴る。

続いてふたつ、みっつ。大陸の端から端へ、無数の鐘の音が波のように広がっていく。それはやがて、大地そのものが鳴っているような、大きくやわらかい和音になる。

港町の外周に、光の線が走る。

線は街をぐるりと囲み、格子状に大地へ沈み込み——**街が、根元からゆっくりと浮き上がる。**

土台ごと切り出された港町。家々の明かりはついたまま。干された洗濯物が夜風に揺れたまま。碇を下ろした船まで、湾の水ごとすくい上げられて。

見れば大陸じゅうで、同じことが起きている。街が、村が、森が、畑が、光の格子に縁取られた巨大なタイルとなって夜空に浮かび、ゆっくりと、盤上の駒のように滑っていく。港町が山あいへ。麦畑が湖のほとりへ。雪をかぶった峰が、砂漠のまんなかへ。

すれ違うふたつの街。互いの窓明かりが一瞬、照らし合う。

音楽、荘厳に。恐ろしい光景のはずなのに、どこか祝祭めいて、美しい。

やがてすべてのタイルが新しい場所に着地する。光の格子がほどけ、大地の継ぎ目が縫い合わされ、鐘の残響が消える。

昨日とはまるで違う地図の上で、大陸はまた、静かに眠っている。

### ○2 とある街区・少女の部屋(夜明け)

小さな屋根裏部屋。ベッドから細い腕が伸び、目覚まし代わりの吊り鈴をちりんと鳴らす。

少女——**ノア(16)**が起き上がる。白い髪。その一房だけが、朝焼けの色に染まっている。

寝ぼけまなこのまま、カーテンを開ける。

窓の外。昨日までたしかに海だった景色が——**一面の雪山**になっている。

窓ガラスに、ぺたりと結晶の花。部屋に流れ込む、きんと冷えた空気。

ノア、驚かない。大きくひとつ伸びをして、白い息を吐き、にっと笑う。

ノア「——今日は、どんな世界かな」

窓の光が画面いっぱいに白く弾けて——

**タイトルロゴ『毎晩世界が組み変わるので、再会屋はじめました』**

### ○3 交易市場(朝)

活気。というより、引っ越し初日の朝のような騒がしさ。

露店の商人たちが慣れた手つきで店を組み直し、屋根の上では男が「東はあっちだー!」と適当な方角を叫び、別の屋根の男が「違う、あっちだ!」と真逆を指す。水売りの少年が「雪山の湧き水だよー、今日限定ー!」と声を張る。昨夜のリロールで隣に来たばかりの雪山を、もう商売にしている。

誰も嘆いていない。世界が組み変わることは、この人たちにとって天気と同じだ。

市場の一角に、ひときわ長い行列。

列の先にあるのは古びた露店。板看板に手書きで**『本日の地図 あります』**。

店主は**カイト(17)**。皮のマップケースを背負い、腰の帯には何十本もの巻き地図。羽ペンを三本の指で回しながら、大判の紙にすさまじい速さで線を引いていく。まだ誰も測量していないはずの「今朝の近隣図」が、彼の手の中でみるみる出来上がる。

その足元、犬が一匹、腹を出して熟睡している。**コンパス**。体はきっちり一直線、鼻先はぴたりと一方向。

カイト「非売品。うちの測量主任だぞ」

ガド「主任は寝てるがな」

ガド「なんでそんなことまで分かる」

ガド「よく言うぜ。四十日前の隣なんて、誰が覚えてるもんか」

客の老婆・**ロダ**が、笑いながら銅貨を数える。

ロダ「この子はねえ、昨日のことを覚えてるんだそうだよ。一昨日も、そのまた前もぜーんぶ」

客B「じゃあ何かい、あたしが先月どこの街の男前と踊ったかも覚えてるってのかい」

カイト「(地図を描きながら、顔も上げず)緑の屋根の楽士街区、広場の東側、相手は笛吹きで、あんた三回も足を踏んでた」

客B「…………」

決まり文句らしい。客たちが「ちがいねえ」と笑って散っていく。

### ○9 三本杉の丘(夜・0時前)

カイト「(懐中時計を開く)0時まで、あと十分……間に合った」

### ○10 新しい土地・市場(翌朝・夜明け)
