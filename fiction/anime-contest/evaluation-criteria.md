# 評価基準: アニメ原作企画コンテスト(異世界ファンタジー)

fable5 / opus4.8 / gpt5.5 が独立に作成したアニメ原作企画を、**企画段階**と**脚本段階**の2段階で評価する。本ドキュメントは応募作を一切見る前に fable5 が作成・確定したものである。

## 評価の公平性について

- AI評価者(fable5)は参加者でもあるため、評価時には成果物を**モデル単位で X / Y / Z と匿名化**し(企画案は X-1, X-2, … と通し番号)、どのモデルの成果物かを伏せる
- 匿名化コピーはモデル名・自己言及の機械的リークチェックを通過させてから評価者に渡す
- 各観点の採点には**企画本文からの引用を根拠として**示すこと(印象点の禁止)
- 前回コンテストの教訓: AI評価の絶対点は独立評価間で±7点程度ぶれる。よって本コンテストでは**同一コンテキスト内での相対比較のみを有効**とし、さらに第1段階の選出は**独立した評価エージェント3体の合議**(後述)で行い、単一評価者のぶれを緩和する

## 第1段階: 企画選考

全参加者の全企画案をひとつのプールとして扱い、**AI選考で3案**を選出する。その後、AI選考に選ばれなかった案から**人間選考で2案**を追加選出し、計5案が第2段階に進む。同一モデルの案が複数選ばれることを妨げない。

### 選考観点(各10点、50点満点)

1. **フックと新規性 — 10点**
   - ログラインの段階で「観たい」と思わせるか。既存の異世界物テンプレの焼き直しになっていないか
   - テンプレを使う場合も、明確な「ずらし」や発明があるか

2. **世界観の物語生成力 — 10点**
   - 魔法・異世界の仕組みに明確なルールと制約があり、都合よく破られない設計か
   - 世界観が背景ではなく、事件・葛藤を12話ぶん自動的に生み続ける装置として機能しているか

3. **キャラクター — 10点**
   - 主人公に独自の「声」と欲望があるか。キャラ同士の関係性に転がせる伸びしろがあるか
   - キャラデザが画として立つか(アニメのキービジュアルが想像できるか)

4. **12話構成 — 10点**
   - 各話あらすじが具体的で、実際に書ける水準か。中だるみしない配置か
   - 1話ごとの満足と、シーズンを貫く縦軸の両立。最終話の着地が納得と余韻を両立するか

5. **第1話プロットの完成度と映像化適性 — 10点**
   - 冒頭(アバン)で掴み、引きで次話へつなぐ構成になっているか
   - 24分の尺感が妥当か。名場面になりうる画が想像できるか
   - 依頼書の演出制約(死者弔い主題の禁止・主要人物を老人にしない・明るいエンタメ調)を守っているか

### 合議方式

1. 独立した fable5 評価エージェント**3体**が、同一の匿名化プールを同一基準で採点する(互いの結果は見せない)
2. 各評価者は全企画案を50点満点で採点し、上位3案を「推薦」する
3. 3体の**合計点で順位を確定**し、上位3案をAI選考の選出とする。同点の場合は推薦数(3体のうち何体が上位3に入れたか)で決す
4. 各評価者のスコアシートと分散(評価者間のぶれ)を選考レポートに記録する

### 人間選考

- 人間(評価オーナー)はAI選考結果と全企画案を見た上で、AI選考外から2案を選ぶ
- 観点は自由(直感でよい)。「アニメ化されたら観るか」を最優先に

## 第2段階: 脚本

選出された5案それぞれについて、3モデル全員が**第1話の脚本**(正味約24分、目安10,000〜16,000字)を執筆する。自分が立てた企画の脚本化も担当する(誰の企画かは執筆者に伏せる)。

企画ごとに脚本3本を匿名化(甲/乙/丙)し、**AIがベスト1本、人間がベスト1本**をそれぞれ選ぶ(一致してもよい)。

### 脚本評価観点(各10点、50点満点)

1. **構成と尺 — 10点**
   - アバン/Aパート/Bパート/引きの構成が機能しているか。24分に収まる現実的な分量・シーン数か

2. **映像演出 — 10点**
   - ト書きが画を喚起するか。「画で語る」演出があるか(説明ゼリフに頼っていないか)
   - 名場面・キービジュアルになるカットが設計されているか

3. **セリフ — 10点**
   - キャラごとに声が書き分けられているか。掛け合いのテンポとユーモア
   - 世界観説明が講義にならず、会話と行動に溶けているか

4. **脚色 — 10点**
   - 企画のプロットの意図を汲みつつ、脚本ならではの膨らませ(具体化・追加ディテール)があるか
   - 膨らませが企画の世界観ルールと矛盾していないか

5. **第1話としての引き — 10点**
   - 視聴者が第2話を観たくなるか。主人公を好きになれるか
   - 依頼書の演出制約(明るいエンタメ調・前向きな視聴後感)を守っているか

### 脚本段階の評価方式

- AI選考は企画ごとに独立した評価コンテキストで3本を同時相対比較する(引用根拠つき)
- 評価者3体の合議は企画数が多いため任意とするが、僅差(合計3点以内)の場合は追加評価者1体を投入して決す
