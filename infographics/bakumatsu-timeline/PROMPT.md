# 幕末〜明治 同期タイムライン教材 — モデル比較評価用共通プロンプト

実施日: 2026-07-04
比較対象: Claude Fable 5 vs Claude Opus 4.8 vs GPT-5.5 (Codex)(同一プロンプト、独立実装)

- Fable 5 の成果物: `fable5/index.html`
- Opus 4.8 の成果物: `opus/index.html`
- GPT-5.5 の成果物: `gpt55/index.html`(Codex CLI サブエージェント経由)

## 共通プロンプト(出力先ディレクトリのみ差し替え)

---

「15 年でこう変わった — 黒船来航から明治改元まで」という、大人の学び直し向けインタラクティブ歴史教材を、単一の HTML ファイルとして実装してください。

### 対象読者と設計思想
- 30 歳以上の知的好奇心旺盛な大人。学校で歴史は習ったが人名・年号は忘れている。予備知識は仮定しない。
- 暗記ではなく「なぜ 260 年続いた幕府が 15 年で倒れたのか」というメカニズムを視覚的に腹落ちさせる。
- 図が主役、文はキャプション。単純な善悪二項対立(開国=正義/攘夷=無知、旧幕府=悪 等)で語らない。

### 成果物
- `{OUTPUT_DIR}/index.html` の 1 ファイルのみ。ビルド工程なしで `file://` で直接開けること。
- 外部ライブラリは `<script type="importmap">` + CDN の ESM import のみ可(使わなくてもよい)。年表・地図等のデータはすべて HTML 内にインラインで埋め込むこと(外部 fetch 禁止)。

### 機能要件
1. **年月スクラバー**: 1853 年 6 月(ペリー来航)〜 1868 年(明治改元)を対象期間とし、ドラッグ・クリック・矢印キーで時間を動かせるスクラバーを置く。再生/一時停止(自動進行)も付ける。
2. **同期マルチトラック年表**: 「政治・幕府」「外交」「社会・経済」「世界」の 4 トラック以上にイベントを帯状に配置し、現在時刻に応じてイベントがハイライトされる。イベントは合計 40 件以上。
3. **勢力図(日本地図)**: スクラバーに同期して、幕府・雄藩(薩摩・長州・土佐・肥前など)・朝廷の立場や勢力の変化が視覚的にわかる日本地図ビュー。地図はデフォルメした SVG で構わない(正確な海岸線は不要)が、地理的位置関係はわかること。長州征討や戊辰戦争の進行が表現できるとなおよい。
4. **「学校ではこう習った → 最新の研究では」カード**: 主要イベント最低 6 件に、従来の教科書的理解と近年の研究による見直しの対比カードを付ける。候補: 「鎖国」概念の見直し(四つの口)/ペリー来航はオランダ別段風説書で約 1 年前に予告されていた/攘夷の背景は無知ではなく開国後の経済ショック/幕府側の近代化努力(横須賀製鉄所・慶応の改革)/明治維新は民衆革命ではない/江戸無血開城の複合的要因、など。
5. **因果の糸**: 「不平等条約 → 開国 → 経済ショック → 政治的動揺 → 倒幕」という因果のつながりを、イベント間の接続やナラティブとして追える表現を入れること(表現方法は自由)。

### コンテンツ要件
- **史実(年月・人物・因果関係)の正確さは評価対象**。年号は月まで正確に(旧暦/新暦の扱いは注記があればどちらでも可)。
- 「最新の研究では」の内容は実在する歴史学の知見に基づくこと。誇張・創作をしない。

### 見た目
- ダークテーマ基調、`<html lang="ja">`、日本語 UI。大人が読む前提の落ち着いた品のあるデザイン。
- PC ブラウザ(幅 1280px 以上)を主対象とする。

### 検証
- 実装後、可能であればヘッドレスブラウザ等で JS エラーが出ないことを確認すること。ブラウザでの動作確認が環境的に不可能な場合は、静的な構文チェックまでで構いません。

### 制約
- 作業は `{OUTPUT_DIR}` 内のみで行うこと。リポジトリ内の他のディレクトリ(特に `infographics/` 配下の他モデルの実装)は参照・閲覧しないこと。
- 最後に、構成・収録イベント件数・工夫した点・既知の制限を簡潔に報告してください。

## 評価観点(メモ)
1. そもそも動くか(JS エラーなく描画・スクラブできるか)
2. 史実の正確性(年月・因果・「最新の研究」の内容が実在の知見か)
3. 同期 UI の完成度(スクラバー⇔年表⇔地図の連動、操作感)
4. 地図表現(デフォルメ SVG でも勢力変化が読み取れるか)
5. 教材としての説得力(メカニズムが腹落ちするか、デザインの品)
