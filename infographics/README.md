# Infographics デモ

グラフィックスを多用した「大人の学び直し」教材を、ブラウザ完結の単一 HTML で作る。
そして本リポジトリの本来の目的にならい、**同一プロンプトを複数モデルに与えて成果物を比較評価する実験台**として運用する（構成は 3DCG/ に準拠）。

## 歴史まなびなおし

### 問題意識

大人になって学び直す最新の明治時代の歴史の教材を作りたい。ブラウザで読むことができ、図表やイラストなどグラフィックスを多用して視覚的に理解しやすいものにしたい。30歳以上の知的好奇心旺盛な大人向けに最新の歴史の知見をおもしろく紹介するにはどんな構成がいいだろうか。

対象は **江戸末期（幕末）から明治にかけての日本の変化**。学校の歴史は人名と年号の暗記に寄りがちで、**「なぜ 260 年続いた幕府が 15 年で倒れ、封建社会が 40 年で近代国家になれたのか」というメカニズム**が抜け落ちやすい。この変化の因果を、地図・年表・データ可視化を多用して視覚的に腹落ちさせる。

### ターゲット

- 歴史に興味はあるが、人名・年号の暗記で挫折した/忘れた一般の大人
- 予備知識は仮定しない。世界史・統計の知識も要求しない

### 設計思想（コンセプト）

- **暗記ではなく変化のメカニズムを教える。** 「何が起きたか」ではなく「なぜ・どうやって起きたか」を軸にする。
- **図が主役・文が従。** 各章は 1 つの中心ビジュアル（同期年表・地図モーフ・データ可視化・before/after）を持ち、それを触ることが理解になる。文章はキャプションに降格。
- **教科書からの差分（最新の知見）で驚かせる。** 各章に「学校ではこう習った → 近年の研究ではこう」の落差を必ず置く（例:「攘夷 = 無知」ではない/維新は民衆革命ではない/士族は勝者ではなかった）。
- **因果の糸を一本通す。** 不平等条約 → 開国 → 倒幕 → 国家建設 → 条約改正、という背骨で全章をつなぐ。
- **単純な善悪・二項対立で語らない。** 開国 vs 攘夷、旧幕府 vs 新政府を勝ち負けの物語にしない。近代化の光と影を両論で。

詳細なカリキュラムと各章のビジュアル設計は [docs/01-concept.md](docs/01-concept.md) を参照。

## モデル比較の進め方

3DCG/ と同じく、章ごとに `<章>/PROMPT.md` を置き、モデルごとのサブディレクトリで独立実装させ、`<章>/RESULTS.md` に比較結果（スクリーンショット付き）をまとめる。各モデルには自分の作業ディレクトリ配下だけを触らせ、他モデルの実装を参照させない。

比較対象モデル: Claude Fable 5（`fable5/`）、Claude Opus 4.8（`opus/`）、GPT-5.5（`gpt55/`、Codex CLI サブエージェント経由）。

## プロンプト履歴

- 初期構想は生物学の学び直し教材だったが、Fable 5 は dual-use のバイオ安全策により生物学（CRISPR・ウイルス・免疫等）で回答を拒否 → Opus にフォールバックしやすく、モデル比較が公平にならないため、被写体を幕末〜明治史に差し替えた（設計思想は流用）。
