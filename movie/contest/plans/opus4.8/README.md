# opus4.8 提出: 健康教育動画 生成システム設計プラン

2案を提出する。**両案は1つのシステムの2つの構成**であり、`manifest.json`(台本+画面設計スキーマ)と Remotion レンダラという背骨を共有し、**中間の「音声合成 + 同期データ生成」だけを差し替える**関係にある。したがって片方を作れば、もう片方は差分実装で載る。

| | プラン01(本命) | プラン02(上位ライン) |
|---|---|---|
| ファイル | [`plan-01.md`](plan-01.md) | [`plan-02.md`](plan-02.md) |
| TTS | VOICEVOX(ローカル・無料) | Style-Bert-VITS2 / ElevenLabs |
| 同期の得方 | **TTS がモーラ timing をネイティブ出力 → ASR 不要で導出** | 強制アラインメント(正解テキスト既知)で timing 復元 |
| 機材 | MacBook 1台で完結 | RTX 4090(合成)+ Mac(描画)の分業 |
| 声の質 | キャラ声・「楽しく気楽」に好適 | 感情表現・自然さが上、看板回向け |
| 1本コスト | 実質50円未満 | 実質100円未満〜(クラウド経路は数百円〜) |
| 強み | 確実・安価・再現性・同期が構造的にズレない | 表現力の上限が高い |

## 使い分け指針

- **全10本の量産は プラン01 を既定ライン**にする。同期が「調整」でなく「導出」される決定論的設計で、最も事故りにくく安く速い。まずこれで10本を通す。
- **導入回・感情の起伏が効く回・対外的な"看板"1〜2本のみ プラン02** に切り替える。声の演技力が主眼で、プラン01の基盤(manifest+Remotion)をそのまま使い回せるため追加コストは小さい。
- 両案は `timeline.json` スキーマが互換。**同じ manifest から音声バックエンドだけ差し替えて AB 比較**でき、回ごとに最適な声を選べる。

## 設計の一貫した思想

1. **同期は導出する** — スライド表示秒を人間や LLM に決めさせない。音声を先に作り、その実測尺に映像を追従させる向きに固定することで、TTS の尺揺れ問題を構造的に消す。
2. **中間成果物をすべてファイルに** — `manifest.json` / `narration.wav` / `timeline.json` / `mp4`。各工程は独立に再実行でき、git で差分管理でき、10本への横展開と将来拡張(縦型ショート・声変更・テンプレ追加)に耐える。
3. **人間は"自動判定が難しく事故ると痛い所"にだけ置く** — 医学的主張の検証(manifest レビュー)と TTS 誤読チェックと最終 QA の3点。尺計算・結合・レンダリングは完全自動のまま残す。
