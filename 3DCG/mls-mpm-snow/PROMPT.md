# MLS-MPM 雪シミュレーション — モデル比較評価用共通プロンプト

実施日: 2026-07-03
比較対象: Claude Fable 5 vs Claude Opus(同一プロンプト、独立実装)

- Fable 5 の成果物: `fable5/index.html`
- Opus の成果物: `opus/index.html`

## 共通プロンプト(出力先ディレクトリのみ差し替え)

---

MLS-MPM(Moving Least Squares Material Point Method)による 3D 雪シミュレーションのデモを、単一の HTML ファイルとして実装してください。

### 成果物
- `{OUTPUT_DIR}/index.html` の 1 ファイルのみ。ビルド工程なしでブラウザで直接開けること。
- CDN からの ES modules 読み込みは可(Three.js 等を使うかどうかは自由)。

### 技術要件
- シミュレーションは WebGPU compute shader で実装すること(P2G → grid update → G2P のループ)。WebGPU 非対応環境ではその旨を画面に表示。
- 雪の構成則: Stomakhin et al. 2013 の弾塑性雪モデル(Fixed Corotated エネルギー + 変形勾配の特異値クランプによる塑性 + 硬化)。
- 粒子↔グリッド転送は APIC/MLS 転送(quadratic B-spline 重み)。
- 粒子数 30,000 以上、60fps を目標。HUD に FPS と粒子数を表示。

### シーン・見た目
- 雪玉が落下し、地面に衝突して崩れ、積もっていくシーン。
- クリック(または数秒おきの自動投下)で新しい雪玉を追加できること。
- レンダリングは 3D でライティングされた見た目にすること(単色の点群は不可)。
- マウスでカメラをオービット操作できること。リセットボタンを付けること。

### 検証
- 実装後、可能であればヘッドレスブラウザ等で JS エラーが出ないことを確認すること。ブラウザでの動作確認が環境的に不可能な場合は、静的な構文チェックまでで構いません。

### 制約
- 作業は `{OUTPUT_DIR}` 内のみで行うこと。リポジトリ内の他のディレクトリ(特に `3DCG/` 配下の他の実装)は参照・閲覧しないこと。
- 最後に、採用した手法・主要パラメータ・既知の制限を簡潔に報告してください。

---

## 評価観点(メモ)
1. そもそも動くか(JS エラーなく描画されるか)
2. 数値的安定性(粒子が爆発・発散しないか、60 秒放置で破綻しないか)
3. 物理的もっともらしさ(雪玉が崩れて積もるか、弾性ゼリーや液体に見えないか)
4. 性能(粒子数と FPS)
5. 見た目の完成度(ライティング、カメラ、HUD)
