# MLS-MPM 雪シミュレーション — Fable 5 vs Opus 比較結果

実施日: 2026-07-03 / プロンプト: [PROMPT.md](PROMPT.md)(同一、独立実装、各 1 回試行)
検証: ヘッドレス Chrome(WebGPU 有効、`--enable-unsafe-webgpu --use-angle=metal`)で自動投下 ON のまま放置し、時系列スクリーンショットを撮影。スクリーンショットは [results/](results/) 参照。

## 結論

**Fable 5 の勝ち。識別課題として機能した。** 両者とも「エラーなく動く WebGPU MLS-MPM」までは到達したが、数値的安定性で明確に分かれた。

| 観点 | Fable 5 | Opus |
|---|---|---|
| JS/WGSL エラー | 0 件 | 0 件(favicon 404 のみ) |
| 起動〜初回衝突 | 雪玉が崩れて堆積 | 概ね堆積するが、この時点で既に迷子粒子が飛散 |
| 14 秒時点 | きれいなマウンド状の積雪、飛散なし | 粒子が空中に飛散、浮遊塊・壁状のアーティファクト発生 |
| 30 秒時点 | 安定(60 秒まで確認、131k 粒子で破綻なし) | **完全に沸騰・爆発状態**。積雪がドーム状に膨張し粒子が噴出 |
| 見た目 | 空グラデーション+地面+ライト付き球、雪らしい質感 | 暗背景+床のみ。粒子サイズが不均一に見える |
| ヘッドレス FPS | 49k 粒子 35fps → 131k 粒子 15fps | 56k 粒子 40fps → 184k 粒子 14fps |

## 分析メモ

- 失敗モードは事前予想どおり「粒子の爆発(数値発散)」。Opus も P2G/G2P・固定小数点 atomic・シェーダ内 SVD といった構成要素は揃えており、**短時間のスモークテストでは合格に見える**のが要注意点。エージェント自身の動作確認(起動直後のスクリーンショット)では問題が検出されなかった。
- 評価プロトコルとして「60 秒放置 + 粒子追加投下」の長時間観察が必須。起動直後の 1 枚では両者を区別できない。
- Fable 5 は FPS 適応のサブステップ制御(dt 固定・ステップ数可変)を入れており、低速環境ではスローモーション化して安定性を守る設計判断をしていた。Opus は粒子増加時も固定 10 サブステップで、蓄積した密集状態に耐えられていない可能性が高い。
- n=1 の比較である点に注意。厳密にやるなら各モデル 3〜5 回試行して安定性の再現率を見るべき。
