# パイロットトピック — 関心を引くネタの候補と試作

curriculum.md の章立てに流し込む前に、「人が食いつくトピック」を単品で試作してトーンと構成を固める。★付きは [drafts/](../drafts/) に試作済み。

選定基準:

- **「え、そうだったの?」がある**。常識の逆転、定説の崩壊、意外な出自 — 物語として面白いこと
- **明日の行動が変わる**。雑学で終わらず、具体的な行動の変更(またはやめてよい努力)につながること
- **エビデンスで白黒(または灰色)がつく**。決着していない論争を断定で語らずに済むネタを選ぶ

## 食事

1. ★ **油の冤罪事件簿** — 40年間悪役だった脂質が実は…。低脂肪ブームの顛末、バターより健康的なはずだったマーガリンの皮肉、高脂肪の地中海食が勝った試験。→ [drafts/food-01-oil.md](../drafts/food-01-oil.md)
2. **卵は1日1個まで?** — 食事性コレステロール神話の40年。各国ガイドラインから上限が消えた話。油の章と姉妹編にできる
3. **「夜10時以降に食べると太る」は本当か** — 食べる時間の科学(time-restricted eating)。半分本当・半分俗説の好例
4. **サプリメントの成績表** — マルチビタミンからビタミンDまで、メタ解析による通信簿。「効かない」証拠の物量で見せる
5. **コーヒー逆転無罪判決** — 発がん疑惑からの完全復権。疫学の交絡(コーヒー好きに喫煙者が多かった)の教材としても優秀

## 運動

1. ★ **運動では(ほぼ)痩せない。それでも最強である理由** — 減量効果は驚くほど小さいという不都合な真実と、それでも運動が全介入中最強である理由。「体重計は運動の KPI として間違い」→ [drafts/exercise-01-weight.md](../drafts/exercise-01-weight.md)
2. ★ **有酸素運動 vs 筋トレ、どっちが勝ち?** — 「両方(役割が違う)」という引き分けの中身。筋トレは独立に死亡率を下げる一軍で、サルコペニア予防=健康寿命の要。J字カーブ(週30〜60分で頭打ち)も → [drafts/exercise-02-aerobic-vs-strength.md](../drafts/exercise-02-aerobic-vs-strength.md)
3. **「1日1万歩」の出どころは万歩計の CM だった** — 1964年東京五輪と「万歩メーター」。実際の用量反応データ(7,000〜8,000歩で頭打ち)
4. **座りっぱなしは「新しい喫煙」か** — キャッチコピーの誇張と、それでも残る実害。相対リスクの読み方(Ch.0)の実践編
5. **筋トレに遅すぎることはない** — 90代でも筋肥大するRCT。健康寿命(介護予防)への直結性では有酸素より上かもしれない話(exercise-02 のサルコペニア節を独立トピックに深掘りする案)
6. **運動おやつ(exercise snacks)** — 1回1〜2分の階段昇降でも効果が出る研究。「時間がない」の言い訳を消す

## 睡眠

1. ★ **寝だめはできるか — 睡眠負債の返済計画** — 週末の寝だめで返せる借金と返せない借金。「眠気の自覚は消えるが能力は落ち続ける」実験の怖さ → [drafts/sleep-01-nedame.md](../drafts/sleep-01-nedame.md)
2. **寝酒は最悪の睡眠薬** — 入眠は早まるのに睡眠を破壊するメカニズム。飲酒章(Ch.5)との相互リンク
3. **ショートスリーパーになれる確率は宝くじ以下** — DEC2 遺伝子変異の話。「慣れ」の正体
4. **昼寝は何分までが正解か** — パワーナップの科学と睡眠慣性。カフェインナップという小技
5. **「お肌のゴールデンタイム22時〜2時」はどこから来たか** — 時刻ではなく「眠り始めの深睡眠」だった話。俗説の発生源をたどる考古学もの

## 人生の楽しみ

1. ★ **お金で幸福は買えるか** — 「年収◯◯万円で頭打ち」説の栄枯盛衰。研究者同士が公開対決(敵対的コラボレーション)した顛末つき。買い方(経験・他人・時間)の科学 → [drafts/joy-01-money.md](../drafts/joy-01-money.md)
2. **孤独はタバコ15本分** — つながりの効果量が生活習慣と同格という衝撃。コース全体の主題(Ch.6)の看板ネタ
3. **モノより経験** — 買い物の幸福の科学。適応(hedonic adaptation)はなぜモノに強く効くか
4. ★ **「生きがい」と死亡率** — 日本発コホート研究が世界で引用されている話。ikigai がそのまま英語になった経緯。相関≠因果の実践編にもなる → [drafts/joy-02-ikigai.md](../drafts/joy-02-ikigai.md)
5. ★ **脳トレより飲み会?** — 認知症予防に本当に効くもの。脳トレゲームの転移効果なし vs 社会参加・運動。「飲み会」の主役は酒でなく交流(酒はリスク側)という線引きが肝 → [drafts/joy-03-cognition.md](../drafts/joy-03-cognition.md)

## アンチエイジング / 長寿科学(Ch.8 — 3レッスン構成)

分野横断の大テーマ。1トピックには大きすぎるため**独立章に格上げし3レッスンに分割**(curriculum.md の Ch.8 参照)。俗説・誇大広告・詐欺が最も密集する領域なので、憲法(エビデンス強度・商品推奨禁止・期待を煽らない)を最も厳しく効かせる。「有望だが未証明」を正直に扱う練習場。共通の合言葉は「動物では本物、ヒトでは未証明」。

1. ★ **Lesson 1 足元編 — 一番効くのはガッカリするやつ** — 老化を遅らせる最強は既知の生活習慣5つ、という身も蓋もない正解。抗酸化サプリの崩壊(喫煙者のβカロテン有害/CARET・ATBC)、カロリー制限(CALERIE で老化ペース約3%減)、老化時計。フロンティアへの地図を張る → [drafts/aging-01-antiaging.md](../drafts/aging-01-antiaging.md)
2. ★ **Lesson 2 フロンティア① 体を若返らせる(再生・巻き戻し系)** — 若い血液/並体結合と Ambrosia の8,000ドル輸血・FDA 警告、セノリティクス(ゾンビ細胞除去/D+Q)、エピジェネティック・リプログラミング(山中因子・緑内障マウスの視力回復/Lu 2020)。各項目をラパマイシン級の解像度で → [drafts/aging-02-frontier-regenerate.md](../drafts/aging-02-frontier-regenerate.md)
3. ★ **Lesson 3 フロンティア② 老化を遅らせる薬・分子 + 詐欺の護身術** — メトホルミン(Bannister の観察データと交絡・TAME)、ラパマイシン(mTOR→オートファジー、動物最強・ヒト未証明)、NMN/NAD+。章の締めに詐欺と有望の見分け方 → [drafts/aging-03-frontier-drugs.md](../drafts/aging-03-frontier-drugs.md)

派生トピック案(まだ書いていない): 老化時計を単独で(「数値で若返りを売る」検査ビジネスの危うさ)、セノリティクスの hit-and-run 投与の面白さを単独で、など。

## 試作から固めたコンテンツの標準構成

4本の試作で使ったテンプレート。アプリの `content/*.js` のスキーマはこれをそのまま構造化する:

1. **フック**(2〜3文): 常識をひっくり返す予告。読者の現在の信念を思い出させる
2. **クイズ**: 「正しいものをすべて選べ」1問・5〜6択。正解2〜4個。誤答選択肢は実在の俗説から作る
3. **正解発表**: 正解列挙 + 一言。部分点の思想(選ぶべきを選ぶ+罠を避ける)
4. **解説本文**: 物語で運ぶ。基本の型は「俗説の誕生史 → 崩壊の瞬間(決定的な研究)→ 現在の科学の到達点」。各主張にエビデンス強度(A〜D)をインラインで付す
5. **選択肢ごとの短評**: 全選択肢に○×と2〜3行の理由。×の選択肢には「この俗説の出どころ」を必ず書く(嘲笑禁止・由来で面白がる)
6. **今日から使える結論**: 3行以内。行動の変更(またはやめてよい努力)で書く
7. **出典**: 主要3〜6本。種別(メタ解析/RCT/コホート等)を明記
