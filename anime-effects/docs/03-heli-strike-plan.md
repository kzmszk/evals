# 計画書 03: ヘリ空爆カット — 3Dレイアウト × セル作画

## ゴール

攻撃ヘリコプターの乗員(ガナー)視点から、ミサイルを発射し、それがビルに着弾して爆発する一連のカットを単一 HTML でリアルタイム描画する。`heli-strike.html` として新規実装する。02 (`cel-explosion.html`) の資産はそのまま流用する。

## 02 からの変更点と、変えない点

02 で確立した土台は正しかったので**変えない**:

- `scene = draw(quantize(t))` — 全要素は量子化時刻の純関数。積分・状態更新なし
- 乱数はすべて `hash(seed, コマ番号)`。スクラブ・コマ送り・完全な再現性
- 爆発雲 = ローブ集合 + セル調 5 段バンド塗り + 離散的な煤遷移 + キノコ化
- インパクトフレーム、十字フラッシュ、コマ単位の離散的な画面揺れ

変えるのは**レイアウト(空間)**:

| | 02 | 03 |
|---|----|----|
| 視点 | 地上からの真横フラット 2D | 斜め上空からの俯瞰(ヘリ乗員視点) |
| 背景 | ベタ塗りシルエット 2 層 | ボックス群による疑似 3D 市街地 |
| 主体 | ビルが勝手に爆発 | ミサイル発射 → 飛翔 → 着弾 → 爆発の因果 |
| 画面演出 | シネスコのみ | + 照準 HUD、コクピット枠、発射反動 |

## 3D の作り方: WebGL ではなくペインターズアルゴリズム

セルルックが目的なので、WebGL は使わず Canvas 2D のまま自前の透視投影で描く。

- **カメラ**: 固定ホバリングではなく**攻撃進入の飛行経路**。目標中心の極座標 `(r, φ)` の閉形式で、距離 1250m・高度 320m から 7 秒かけて 570m・235m まで接近減速し、着弾後はバンクしながら西側へ約 45° 回り込む(オービット)。機首(視線)は常に目標をトラッキングし、ロールは旋回率 `dφ/dt` に比例。接近後は立ち上るキノコ雲へゆっくりティルトアップする。揺らぎは量子化時刻の sin 合成 + コマ単位のジッタ
- **投影**: ピンホール(焦点距離 f=900px 相当)。ワールド → ヨー・ピッチ回転 → 透視除算。ニアプレーン(z=4m)でポリゴンをクリップ(Sutherland–Hodgman)
- **市街地**: 132m ピッチの街区グリッドに seed 生成のボックス群(約 130 棟 + 遠景ベルト約 45 棟)。凸なので**面法線の裏面カリングだけで面順序は不要**、ボックス同士は奥→手前にソート(ペインターズ)
- **セル調シェーディング**: 面の色は「屋上 / 順光面 / 逆光面」の 3 色のベタのみ。距離で 4 段階に量子化した大気ヘイズ色に混ぜる(連続フォグにしない)
- **夕景は逆光**: 太陽は画面左端外の低い位置。正面の壁は影色、左向きの壁だけ西日のリムが乗る。地面に h×2 級の長い影(平行四辺形 2 枚で近似)
- **窓明かり・屋上構造物・航空障害灯**: 近景のみ。窓は 1 ビルあたり 1 パスにまとめて描画

**爆発は 3D 化しない**。実際のアニメ同様、爆発セルは 2D のまま、着弾点の投影位置とスケール `s = f/z` でビルボード合成する。02 の `drawBurst` をローカル座標(メートル)化して `s` 倍するだけ。

| 時刻 | 内容 |
|------|------|
| 0.0 | ホバリング。HUD がターゲットボックスをサーチ(枠が収束していく) |
| 0.9 | LOCK。ボックス実線化、"LOCK" 点滅 → 固定 |

## レイヤー構成(奥 → 手前)

1. 空(ベタ帯 6 段、地平線位置はカメラピッチから算出)+ 太陽/月 + フラット雲(遠方ビルボード)
2. 地面(巨大クアッド)+ 地平線際のヘイズ帯(2 段量子化)+ 道路グリッド
3. ビルの落影(近景のみ)
4. **深度ソート済み描画リスト**: ビル群 / 主役ビル(無傷 → 焦げスタブ + 倒壊上部)/ 爆発グループ(雲・リング・地走り・火の粉)/ 破片(各個)/ ミサイル + 煙パフ(各個)/ 発射フラッシュ
5. 機体パーツ(パイロン + ミサイルラック。画面固定 = 揺れの外)
6. 白フラッシュ / HUD / ビネット / シネスコ帯

## ヘリ乗員視点の記号

- **照準 HUD**(アンバー、夜は FLIR 風グリーン): 中央レティクル、ターゲット捕捉ブラケット、距離・高度・方位・"AGM-114 ×4→×3"・状態表示(SRCH → LOCK → FLY → IMPACT)
- **機体の存在**: 右下にミサイルパイロンのシルエット(発射後は空になる)、下隅にキャノピー枠のダークウェッジ
- **反動と衝撃**: 発射時のピッチキック、着弾 0.2 秒後の大揺れ。揺れは 02 同様コマ単位の離散ジャンプ

## ハマりやすい点

- ニアプレーンクリップを省略すると、道路・地面・衝撃波リングがカメラ背後に回った瞬間に破綻する。ポリゴンはカメラ空間でクリップしてから投影する
- ボックスの面の向きは頂点順に依存させない。法線は「面中心 − ボックス中心」で外向きに矯正してからカリングする(倒壊で回転しても壊れない)
- 爆発を 3D で作ろうとしない。ビルボード + `s=f/z` 倍で十分で、その方がセル画に見える
- 描画はコマが変わったときだけ再実行する(レンダーキャッシュ)。60fps の rAF で毎回描くと窓ポリゴンが無駄に重い
- 発射位置はカメラポーズの純関数として求める(カメラ基底ベクトルから機体オフセットを復元)。`Math.random()` 同様、状態として持つと決定論が壊れる
