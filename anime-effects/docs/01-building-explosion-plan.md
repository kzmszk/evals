# 計画書 01: ビル爆破カット - 流体シミュレーションによるアニメ風エフェクト

## ゴール

高層ビルの窓や側面から炎・煙・粉塵が噴き出し、衝撃波と破片が重なる「アニメでよくあるビル爆破シーン」を、単一 HTML でリアルタイム描画する。

このデモは爆発物や構造破壊の正確な物理再現ではなく、映像演出としての爆破カットを目標にする。特定作家の絵柄をそのままコピーするのではなく、特撮アニメ的な「白い衝撃」「黒い煙の面」「爆炎の花弁状シルエット」「数フレームの止め」を抽出して使う。

流体シミュレーションは主役ではなく、煙・粉塵の揺らぎレイヤーとして扱う。主役はハードエッジの作画レイヤー、衝撃線、フラッシュ、画面揺れ。

## 技術選定

- 2D Stable Fluids 風の格子シミュレーション。
  - 半ラグランジュ移流
  - 圧力射影
  - 簡易 vorticity confinement
  - 障害物マスク
- Canvas 2D の `ImageData` に流体を描き、ビル・破片・衝撃波・爆発雲を通常の 2D 描画で重ねる。
- 外部ライブラリなし。`file://` で動く。

## 解像度と座標

- 表示キャンバス: 960 x 540
- 流体グリッド: 192 x 108
- 1 グリッドセル = 表示 5 px
- 速度単位: グリッドセル / 秒
- `dt` は `1 / 30` 秒でクランプする。タブ復帰時に巨大 dt が入っても破綻させない。

## フィールド

| フィールド | 内容 |
|-----------|------|
| `ux`, `uy` | 速度 |
| `pressure` | 圧力 |
| `divergence` | 発散 |
| `smoke` | 黒煙 |
| `dust` | 粉塵 |
| `heat` | 温度・浮力 |
| `fire` | 発光する炎 |
| `obstacle` | ビルの障害物マスク |

`smoke`, `dust`, `heat`, `fire` は同じ移流関数で運ぶ。散逸係数は炎を大きめ、煙と粉塵を小さめにする。

追加で、流体とは別の作画レイヤーを持つ。

| レイヤー | 内容 |
|----------|------|
| `blasts` | 花弁状の爆炎・黒煙ローブ。円ではなく揺らいだ多角形で描く |
| `speedLines` | 放射状の衝撃線 |
| `waves` | 白橙の衝撃波リング |
| `particles` | 火花・破片 |
| `flash`, `shake`, `freeze` | 画面全体の白飛び、揺れ、数フレームの止め |

## 毎フレームの処理

1. `dt = min(realDt, 1 / 30)`
2. ユーザー入力・自動演出イベントで速度とスカラー場を注入
3. vorticity confinement で巻き込みを強調
4. 熱と煙による浮力を速度に加える
5. 圧力射影で非圧縮っぽく整える
6. 速度場を半ラグランジュ移流
7. 再度圧力射影
8. `smoke`, `dust`, `heat`, `fire` を移流・散逸
9. 背景 -> ビル -> 流体 -> 爆炎雲 -> 衝撃線 -> 火花/破片 -> 白フラッシュ/ビネットの順で合成

## 障害物マスク

ビルは中央やや右の縦長矩形を基本形にする。流体グリッド上では `obstacle[i] = 1` のセルとして扱う。

- 障害物内の速度は 0 にする
- 障害物内のスカラー場は減衰させる
- 圧力計算の近傍参照で障害物セルは現在セル値扱いにする
- 注入点は窓や側面の内側に置いてよい。半径を持つ注入なので、外側へはみ出た成分が流体として見える

## 爆破イベント

`startExplosion()` でタイムラインを 0 に戻し、以下のイベントを順番に発火する。

| 時刻 | 内容 |
|------|------|
| 0.08s | 中央で大爆発、白フラッシュ、短い止め |
| 0.16s | 中段左窓から横向き爆炎 |
| 0.23s | 上段右窓から横向き爆炎 |
| 0.34s | 中央左から粉塵混じりの爆風 |
| 0.50s | 右側面から横向き爆風 |
| 0.72s | 低層左側から粉塵噴出 |
| 0.95s | 屋上近くから黒煙 |
| 1.18s | 地面付近の粉塵クラウド |

各イベントは以下を行う。

- 半径内に radial velocity を加える
- `fire`, `heat`, `smoke`, `dust` を追加する
- 破片パーティクルを生成する
- 衝撃波リングを生成する
- ダメージ表示用の scorch mark を記録する
- 花弁状の `blasts` を生成する
- `speedLines`、`flash`、`shake`、`freeze` を加える

## レンダリング

### 背景

夜の都市背景を Canvas 2D で描く。星や遠景ビルは控えめにして、主役のビルと煙が読みやすいようにする。

### 流体

`ImageData` でグリッドごとに色を作る。

- `fire` は黒 -> 暗赤 -> 橙 -> 黄 -> 白の ramp
- `smoke` は青みのある黒灰色
- `dust` は土煙寄りの灰褐色
- しきい値と量子化でセル画風の塊にする
- 透明度は `fire`, `smoke`, `dust` の合成から決める

流体は滑らかになりやすいので、主役にしない。煙の奥行きと残り香を作るためのレイヤーと考える。

### 爆炎雲

爆発らしさの中心。`blasts` は揺らいだ円形パスで描く。

- 外側は太い黒または濃い赤茶の面
- 内側は白 -> 黄 -> 橙 -> 赤 -> 黒煙へ遷移
- 円形グラデーションではなく、塗り分けられた面として描く
- 大爆発は中心に白いコア、周辺に複数のローブを置く
- 横爆風はローブの重心を左右へ伸ばす

### ビル

ビル本体は流体の上に半透明で重ねる。窓、亀裂、焦げ跡を描く。

- 爆発前の窓は鈍い青
- 発火済みイベント周辺は黒い穴と赤橙の縁
- タイムライン後半は亀裂線を増やす

### 破片と衝撃波

破片は重力つきパーティクル。火花は短寿命の明るい粒。衝撃波は薄い白橙のリング。

### 画面演出

- 大爆発の瞬間だけ `flash` を 1 に近づけ、画面を白く抜く
- `freeze` で数フレームだけシミュレーションを止め、衝撃を読ませる
- `shake` でビルと背景を揺らす
- 放射状の `speedLines` を 0.2-0.4 秒だけ表示する

## UI

- `爆破`: タイムラインを最初から再生
- `リセット`: 流体・パーティクル・タイムラインを初期化
- `演出`: アニメ / 粉塵多め / 炎多め
- `爆風`: radial velocity と破片速度の倍率
- `煙量`: `smoke` と `dust` の注入倍率
- `渦`: vorticity confinement の強さ
- `一時停止`
- FPS 表示

## ハマりやすい点

- CPU 実装なのでグリッド解像度を上げすぎない。192 x 108 で十分。
- 圧力 Jacobi 回数を増やしすぎると重くなる。12-18 回を目安にする。
- 炎と煙を同じ減衰にすると、炎が残りすぎるか煙が消えすぎる。炎は強く減衰させる。
- 障害物内で流体が残るとビルが光って見える。マスク内は毎フレーム減衰またはゼロ化する。
- 物理的な色よりも、遠目に読めるシルエットと明暗差を優先する。
