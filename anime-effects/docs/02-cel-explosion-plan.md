# 計画書 02: ビル爆破カット・改 — 「シミュレーション」から「作画」への転換

## ゴール

庵野秀明的なビル爆破カット(DAICON・トップをねらえ!・ナディア・エヴァ系譜の爆発)を、単一 HTML でリアルタイム描画する。計画書 01 / `building-explosion.html` は残し、本計画は `cel-explosion.html` として別実装する。

## 01 の何が根本的に違ったか

01 は「流体シミュレーション + アニメ風レイヤーを上乗せ」という構成だった。結果がアニメに見えない理由は、装飾の不足ではなく土台の選択にある。

| # | 問題 | 内容 |
|---|------|------|
| 1 | **60fps の連続運動** | 流体は毎フレーム滑らかに変化する。アニメの爆発は 2〜3 コマ打ち(8〜12fps)で、形が離散的に「差し替わる」。滑らかさそのものがアニメらしさを殺す |
| 2 | **グラデーションと半透明** | グリッド流体の描画は本質的にぼけた濃度場。セル画は 4〜5 段のベタ塗りの面で、境界はハードエッジ |
| 3 | **形の言語が違う** | 庵野爆発の雲はカリフラワー状のローブが集積した彫刻的シルエット。拡散方程式からは丸ボケしか出ない |
| 4 | **タイミングが物理時間** | 演出上の爆発は「数コマで急拡大 → ほぼ静止して微成長(スローイン)」。実時間の物理では出ない緩急 |
| 5 | **演出記号の欠如・弱さ** | インパクトフレーム(白黒反転コマ)、十字フラッシュ、地走り煙(特撮の地を這う粉塵)、シルエット破片、点滅する航空障害灯。これらは流体からは生成できない「記号」 |

結論: **流体ソルバを捨てる**。煙・炎の動きは手描きアニメーターがやるように、形状ライブラリ(ローブ群)とタイミングチャートで直接作る。

## 方針の逆転: フィルムストリップ・モデル

01 が「状態を毎フレーム積分するシミュレーション」だったのに対し、02 は**全要素を『量子化された時刻 t の純関数』として実装する**。

```
scene = draw(quantize(t))
```

- 積分・状態更新を持たない。破片の弾道も雲の成長も崩壊も、すべて t の閉形式で計算する
- 時刻を 24fps 基準の「コマ」に量子化してから描く。コマ打ち(1/2/3 コマ)は量子化幅の変更だけで実現できる
- 乱数はすべて `hash(seed, コマ番号)` 由来。同じコマは常に同じ絵 = 止めコマが完全に静止し、コマが変わると形が「差し替わる」(手描きのブレ = ボイル)
- 副産物として**タイムラインのスクラブ・コマ送り・完全な再現性**が手に入る。流体では原理的に不可能だった機能

## 要素仕様

### 爆発雲(主役)

**構造**: 雲 = ローブ(円形の瘤)の集合。主爆発は約 22 個 + 成長中に湧く子ローブ 16 個。各ローブは角度・距離比・半径比・煤バイアスを seed から一度だけ生成。

**成長カーブ**: `G(τ) = R · τ/(τ+0.22) · (1 + 0.16·√max(0, τ−0.6))`。最初の数コマで 8 割まで拡大し、以後は微成長(スローイン)。

**セル調バンド塗り**: 各ローブを 5 段のバンドで塗る。外側から「こげ茶の輪郭 → 暗赤 → 橙 → 黄 → クリーム白」。バンドごとに半径を縮め、中心を光源方向(左上)へオフセットした blob パスを**全ローブまとめて 1 パスで塗る**。重なりの谷間が自然に暗く残り、カリフラワー状の質感が出る。

**白玉ステージ**: 発生直後 τ < 0.12 は全体を白 1 色 + 橙輪郭で塗る(爆発の最初の「白い玉」)。

**煤遷移**: 各ローブは `soot(τ, bias)` を 4 段階に量子化し、火パレット → 茶煙 → 灰煙へ**離散的に**切り替わる(連続補間はしない)。芯と柱は火が長持ちし、外周から煤ける。

**キノコ化**: τ ≈ 1.1〜2.6 で球状配置からキノコ配置(傘 + 柱)へ位置を閉形式でモーフ。傘は上昇しつつ扁平に広がり、柱は中心へ収束する。

**ボイル**: blob の歪み位相はコマ番号ハッシュ。コマが変わるたびに輪郭が差し替わる = 中割りのない手描きの沸き。

### インパクトフレーム

主爆発の瞬間 4 コマ、コマ打ち設定に関係なく 24fps の 1 コマ打ちで、爆心から放射する三角スパイクの白地黒 / 黒地白を交互に全画面表示。各コマは別 seed。OFF トグルあり。

### その他の記号

- **十字フラッシュ**: 縦長の 4 芒ダイヤ。白芯 + 橙ハロ。数コマで収縮。誘爆はスケール 0.35 のミニ版
- **衝撃波リング**: 爆心の水平楕円が数コマで画面外へ。白の太線 + 橙の細線、透明度は段階量子化
- **破片**: 30 個の黒シルエット多角形 + 大判スラブ。位置は弾道の閉形式 `p(τ) = p₀ + v₀τ + ½gτ²`、量子化時刻で描くだけでステップ運動になる。τ < 0.8 は片側エッジが橙に灼ける
- **ビル崩壊**: 中層は主爆発で消失(火球が隠す)。上部躯体は 1.55s から自由落下 + 傾き、下部は破断面がジグザグ + 灼けエッジ。窓明かりは全滅、非常灯だけ点滅
- **地走り煙**: 左右に puff チェーンを配置し、先端距離 `D(τ) = Dmax·τ/(τ+0.9)` で走らせる。茶灰 4 段のバンド塗り
- **画面演出**: 揺れはコマ単位で新しいオフセット(滑らかに揺らさない)。主爆発でパンチズーム 1.045 → 1.0。フラッシュ減衰も 1/4 刻みに量子化

## UI

- `爆破`: 頭から再生
- `再生 / 停止`、`◀コマ / コマ▶`(コマ送り)、タイムラインスクラブバー
- `コマ打ち`: 1 / 2 / 3 コマ(デフォルト 2)。リミテッドアニメの効果を体感するための主役コントロール
- `時間帯`: 夕景 / 夜 / 昼
- `インパクトフレーム` ON/OFF、`シネスコ` ON/OFF
- タイムコード表示(t 秒 + コマ番号)
- キーボード: Space 再生停止、←→ コマ送り

## ハマりやすい点

- 乱数に `Math.random()` を使うとスクラブの決定論が壊れる。すべて seed + コマ番号のハッシュにする
- バンドのオフセットを大きくしすぎると内側バンドがローブからはみ出す。オフセットはローブ半径比で管理する
- 煤遷移を連続補間するとセル感が消える。必ず 4 段に量子化する
- インパクトフレームだけはコマ打ち設定と独立に 24fps。2 コマ打ちに巻き込むとリズムが鈍る
- 揺れを sin で滑らかにやると途端に CG っぽくなる。コマごとの離散ジャンプにする
- 終端で自動停止した後もボイルが止まって見えるのは「カット終わり」として許容する
