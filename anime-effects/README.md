## 実行方法

`building-explosion.html` をダブルクリックして開く。ローカルサーバーでもよい:

```sh
python3 -m http.server 8000
```

## 方針

- **単一 HTML ファイル完結**。CSS / JS はインライン、外部 CDN は使わない。
- 流体は煙・炎・粉塵の大きな動きに使い、破片・火花・衝撃波は別レイヤーで描く。
- 物理正確性より、アニメのカットとして気持ちよく見えるタイミング・色・輪郭を優先する。
- `file://` で動くように `fetch` やモジュール分割は避ける。
