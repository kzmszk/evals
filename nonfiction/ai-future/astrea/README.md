# ASTREA — AIの未来を、社会の選択へ。

`nonfiction/README.md` の課題への独立した astrea 版。一般読者が読む長編論考と、政策説明の準備に使うブリーフ、一次資料、仮定を動かす国別モデルをまとめたサイトです。既存版は `../site/` に残しています。

## 起動

```bash
npm ci
npm run dev
# http://localhost:5174
npm run build
npm test
```

## 内容

| URL | 内容 |
|---|---|
| `/` | 要点、図表、2026〜2036年の条件付き見通し、予測の読み方、用語 |
| `/llm` | 知能と仕事の論考（約2万字）、METR測定値、目次、印刷 |
| `/physical` | フィジカルAIの論考（約1万字）、電力とロボットの図表 |
| `/simulator` | 4地域、10の条件、AI追加普及なしとの比較、CSV出力 |
| `/policy` | 政策向け要約、担当領域と観測指標、Q&A、印刷/PDF保存 |
| `/evidence` | 出典検索、対象年・推計方法・限界、測定データ表 |
| `/method` | 国別係数、全数式、モデルの省略事項 |

## 編集とデータ

- 編集基準日：2026-09-09。資料の対象年・公開日・取得日は区別しています。
- `articles/`：Markdownの長編本文。H2から自動で目次を生成。
- `research/`：根拠調査メモ。ウェブ記事はこのメモ自体ではなく原資料を引用。
- `src/evidence.ts`：出典台帳。更新する際は対象年と版も合わせて確認。
- `src/data/metr.json`：METR TH1.1公開YAMLの2023年以降のモデル。分単位、p50/p80、元データの不確実性範囲、取得日、SHA-256を保持。16時間を超える中心推定には測定限界を表示。
- IEA電力は2026年版の2025年485TWh→2030年950TWh、IFRロボットは2024年の設置を使用。AI専用電力やヒューマノイド台数と混同しません。
- `src/model.ts`：依存を持たない年次モデル。係数は統計的に推定していない例示用の仮定。国別の実際の失業率・GDPや政策効果の予測ではありません。
- 家計所得指数は標準政策の2026年を固定分母に使います。給付・税の操作によって分母が動き、見かけの効果が逆転することを防いでいます。
- CSVには仮定のコメント行と全4地域の年次データを含めます。

## 検証

`npm test` は年次の労働ストック保存、所得・財政会計、初期値、AI追加普及なし、税・給付の効果、地域別供給遅延、入力範囲を確認します。ブラウザでの目視・操作試験は未実施です。

WebMCP対応ブラウザでは `configure_ai_scenario` を登録します。未対応環境では通常の操作に影響しません。対応ブラウザでの登録・操作検証は未実施です。

## 構成

React / TypeScript / Vite。バックエンド・APIキー不要。サイト全体を静的配信できます。BrowserRouterを使うため、配信先は存在しないパスを `index.html` に戻すSPAフォールバックを設定してください。Sites向け静的出力は `.openai/hosting.json` に宣言しています。

## 制作依頼

> nonfiction/README.md を読み、astrea 版 ai-future の解説サイトを構築してほしい。たとえば政治家や官僚に説明するための準備資料としても通用するものにしてほしいし、一般の人にも読みやすいようにしてほしい。君の能力の許す限り最大限の努力をはらって作品をしあげてくれ。調査など単純作業は luna など軽量で高速なモデルを使うことを推奨する。高速化のために並行作業をさせてもかまわない。
