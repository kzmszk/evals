# ノンフィクション生成デモ

## AIの未来についての論考

### 課題感
AIの進化がはげしい。Situational Awareness や AI2027 などAI進化の社会への影響を予測する文書はいくつかあるが、Mythos や Fable の騒動を経験した上でさらに精度をあげた予測をまとめていきたい。特に自分が興味ある点は下記のような点である。

* AGI（ぼぼ人間と同等の知的能力を持ち、人間のトップクラスの研究者・エンジニアと同等の作業を自力で行うことができる）に到達することは可能か、可能とすればいつごろになりそうか
* AIの進化により知能爆発は起きるのか、おきるとすればいつ頃か。
* AIの進化により産業爆発はおきるか、おきるとすればいつ頃か。どんな条件があれば産業爆発はおきるのか。
* 雇用への影響、UBIなどの導入がどのようなものになるか、国別にいくつかシナリオを検討したい。雇用の悪化の程度、UBIなどの再分配の導入可否や導入速度、社会の不安定化、国際関係への影響。
* たとえば日本のように解雇規制が強く労働流動性が低い国でどうなるか、米国のように流動性が高い国でどうなるか
* 米国や中国のようにAI開発の先進国と日本やEUのようなAI開発に遅れている国ではどうか
* フィジカルAIについてはどういう状況か
* 中国の政策（輸出規制など）がロボットやフィジカルAIの面で世界に及ぼす影響はどのようになるか
* アメリカは十分な電力とデータセンタを国内でまかなえるのか
* 中国以外で十分な数のロボットを生産できるのか。 

### 方針
* AIの発展に関連する重要な公開データを収集し、分析・可視化できるようにする。
* 過去に行われた予測と現状と比べて予想がどの程度正確だったか、見落としていたものはあったか整理する。
* マクロ経済モデルを利用してありうる未来を予測できるようにする
* 今後10年程度のAIの進化と社会への影響をできるかぎり具体的に予想する
* 予想する上で分岐するイベントはできるかぎり具体的に予想する

### 成果物
* 現状の（主にLLM系統の）AIの分析、過去の論考の課題、今後１０年の予想を２万字程度のブログ記事
* ブログ記事から参照するデータを可視化したもの
* マクロ経済モデルなどによる国別GDP・失業率・社会安定性のシミュレーション
* 現状のフィジカルAIの分析、今後１０年程度の予想を１万字程度のブログ記事
* 上記をまとめたPC向けのWEBサイト

### 評価基準
* UI/UXがわかりやすい
* 参照データは関連性が高く、正確である
* ソースコードは見通しやすく、メンテナンスが容易である
* ブログ記事は論旨が明確で、一般の読者でも理解でき、文章として魅力的である（読ませる）。
