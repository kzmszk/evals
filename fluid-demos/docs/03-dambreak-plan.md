# 計画書 03: ダムブレイク — 粒子法 (Double Density Relaxation)

## ゴール

水柱が崩れて床を走り、壁に打ち付けて飛沫が上がるダムブレイク。
水はメタボールで「液体の面」として描き、速い部分は白く（泡）。マウスで水をかき混ぜられ、重力を傾けられる。
2500 粒子で 60fps。

## 技術選定

- **Clavet, Beaudoin, Poulin (2005) "Particle-based Viscoelastic Fluid Simulation" の Double Density Relaxation**。
  - 理由: 古典 SPH（Müller 2003）は剛性と dt の兼ね合いがシビアで substep が多くなる。
    Clavet 法は「位置を直接緩和して最後に v=(x−x_prev)/dt で速度を回収する」位置ベースで、
    大きな dt でも安定。ゲーム/デモ用途の定番で実装も短い。
- 描画は Canvas 2D。メタボールはオフスクリーン合成＋αしきい値処理。

## 1 substep の処理（Clavet の順序が重要）

q = r/h（q ≥ 1 の対は無視、i=j は除外）として:

1. `v += g · dt`
2. **粘性（ペア一括, i<j で1回）**: `u = (v_i − v_j)·r̂` が u > 0 のとき
   `I = dt · (1−q)(σu + βu²) · r̂` 、 `v_i −= I/2; v_j += I/2`
3. `x_prev = x` を保存し、 `x += v · dt`
4. **Double density relaxation**（粒子 i を順に、更新済み位置を使う Gauss–Seidel 型で処理）:
   - `ρ = Σ_j (1−q)²` 、 `ρ_near = Σ_j (1−q)³`
   - `P = k(ρ − ρ0)` 、 `P_near = k_near · ρ_near`
   - 各近傍 j: `D = dt² · (P(1−q) + P_near(1−q)²) · r̂` 、 `x_j += D/2; x_i −= D/2`
5. **壁**: 位置を箱内へクランプ（めり込み分だけ押し戻す）。障害物 AABB は最小めり込み軸方向へ押し出す。
6. `v = (x − x_prev) / dt` ← **これが肝**。壁の反発・減衰も位置補正から自然に出る。
   滑りすぎる場合のみ壁面で接線速度に 0.99 程度の減衰を掛ける。

## 近傍探索

- セルサイズ h の一様グリッド（`head[]` + `next[]` の連結リスト、毎回 O(N) で再構築）。近傍は 3×3 セル。
- substep 内で 2 回構築する: 粘性パス用（移動前の位置）と DDR 用（移動後の位置）。
- ペア処理は i<j で 1 回だけ（対称に半分ずつ作用）。

## ρ0 / k の調整方法（実装手順 2 でやる）

1. 箱の下半分に粒子を充填して放置し、静止時の平均 ρ をコンソールに出す
2. その実測値を ρ0 にする。ρ0 が小さすぎると沸騰したように膨らみ、大きすぎると塊のまま崩れない
3. k を上げると非圧縮性が上がるが震え出す。静止時に水面が平らで、粒がほぼ止まる k を選ぶ

Node.js でヘッドレスに回して `最大速度・平均密度・NaN` を確認するのが速い（canvas 不要、物理だけ切り出す）。

## レンダリング（見栄えの9割はここ）

1. **オフスクリーン canvas（解像度 1/2）** に、粒子ごとにスプライトを `drawImage`。
   スプライトは事前生成した放射状グラデーション（半径 ≈ h·0.75·0.5、中心 α=1 → 端 α=0）で、
   **速度 |v| に応じて 8 段階に色分け**（深青 #123e8c → 水色 #63b3f0 → 白 #ffffff。|v|/900 で正規化）。
2. `getImageData` で **α しきい値処理**: a<70 → 透明、70≤a<110 → ソフトエッジ（(a−70)×3.5）、それ以上 → 不透明。
   これで粒の集まりが「一枚の液面」になる（メタボール）。
3. メイン canvas に等倍拡大で描画（imageSmoothing 有効）。
4. 背景は縦グラデ（#0b0e14 → #11161f）、タンクの壁と障害物を線で描く。
   |v| > 700 の粒子に小さな白ドットを重ねると泡の質感が出る（任意）。

## 落とし穴

- **v を先に更新する古典 SPH 流に書き換えないこと**。「位置を直接動かし、最後に v=(x−x_prev)/dt」が安定性の源泉。
- k・k_near は dt² に掛かる。**substep 数を変えたら要再調整**。
- DDR の displacement を「全部計算してから一括適用」(Jacobi 型) にすると振動しやすい。逐次適用（Gauss–Seidel 型）のままに。
- 初期充填間隔は s = h·0.4〜0.5。h に近すぎると近傍が少なく密度評価がスカスカになる。
- しきい値処理の getImageData は半解像度なら毎フレーム呼んで問題ないが、フル解像度では重い。
- 粒子座標に NaN が一度混ざるとグリッド経由で全体へ伝染する。開発中は定期的に `Number.isFinite` チェックを。
