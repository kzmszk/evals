# 計画書 01: カルマン渦列 — 格子ボルツマン法 (LBM D2Q9)

## ゴール

円柱などの障害物の後流に、渦が左右交互に剥がれて流れていく「カルマン渦列」をリアルタイム表示する。
渦度（curl）の発散型カラーマップ＋流されるトレーサー粒子で見せる。マウスで障害物を自由に描ける。60fps 目標。

## 技術選定

- **格子ボルツマン法 (LBM) D2Q9 + BGK 衝突**。ナビエ・ストークスを直接離散化するより実装が単純で、
  安定条件が明快（τ > 0.5, |u| < 0.15 程度）。CPU の TypedArray で十分に速い。
- 描画は Canvas 2D。シミュレーション格子解像度の ImageData に渦度カラーを書き、`drawImage` で拡大。

## 格子と定数

- `NX=400, NY=160`、表示倍率 `SCALE=3`（canvas 1200×480）
- D2Q9 の速度ベクトル・重み・反対方向:

| i | e_i | w_i | opp(i) |
|---|-----|-----|--------|
| 0 | ( 0, 0) | 4/9  | 0 |
| 1 | ( 1, 0) | 1/9  | 3 |
| 2 | ( 0, 1) | 1/9  | 4 |
| 3 | (-1, 0) | 1/9  | 1 |
| 4 | ( 0,-1) | 1/9  | 2 |
| 5 | ( 1, 1) | 1/36 | 7 |
| 6 | (-1, 1) | 1/36 | 8 |
| 7 | (-1,-1) | 1/36 | 5 |
| 8 | ( 1,-1) | 1/36 | 6 |

（y の向きは画面座標(下向き)でも数学座標でも、一貫していれば良い）

- データ: `f, fTmp = Float32Array(9*NX*NY)`（添字 `i*NX*NY + y*NX + x`）、
  `rho, ux, uy = Float32Array(NX*NY)`、`barrier = Uint8Array(NX*NY)`
- **ダブルバッファ必須**。ストリーミングを同一バッファで行うと縞状アーティファクトが出る。

## 1ステップの処理

1. **衝突 (collide)**: 各非障害物セルで
   - ρ = Σ f_i、u = (Σ e_i f_i) / ρ
   - 平衡分布 `feq_i = w_i ρ (1 + 3(e·u) + 4.5(e·u)² − 1.5|u|²)`
   - `f_i += ω (feq_i − f_i)`、ω = 1/τ、**τ = 3ν + 0.5**
   - このとき rho/ux/uy 配列に保存（描画・粒子移流で使う）
2. **ストリーミング (pull 方式)**: `fTmp[i][x,y] = f[i][x−e_ix, y−e_iy]`
   - 参照元が障害物セルなら **バウンスバック**: `fTmp[i][x,y] = f[opp(i)][x,y]`
   - 参照元が左域外 (x<0) なら流入平衡分布 `feqIn[i]`
   - 終わったら f と fTmp を swap
3. **境界条件**:
   - 流入 (x=0 列): 毎ステップ平衡分布 (ρ=1, u=(u0, 0)) で上書き固定
   - 流出 (x=NX−1 列): x=NX−2 列のコピー（勾配ゼロ）
   - 上下壁 (y=0, y=NY−1 行): barrier=true（バウンスバックの無滑り壁）

## パラメータ（推奨初期値）

| 項目 | 範囲 | 既定 | 備考 |
|------|------|------|------|
| u0（格子単位の流入速度） | 0.03〜0.13 | 0.10 | 0.15 超は Mach 数過大で不安定 |
| ν（動粘性） | 0.005〜0.2 | 0.02 | τ = 3ν+0.5 ≥ 0.51 を必ず保証 |
| 円柱半径 r | 6〜20 | 10 | 中心 (NX/5, NY/2) |
| ステップ/フレーム | 1〜6 | 3 | |

- **Re = u0·(2r)/ν** を UI に常時表示。既定値で Re=100。渦列は Re ≳ 50 から現れる。
- 完全対称だと渦剥離開始まで非常に長い。**非対称の種を必ず入れる**:
  障害物中心を y 方向に 1〜2 セルずらす ＋ 初期化時に微小な vy 揺らぎ（例: `0.05·u0·sin(2πy/NY)`）を入れる。

## 可視化

- 渦度: `curl = 0.5·((uy[x+1,y] − uy[x−1,y]) − (ux[x,y+1] − ux[x,y−1]))`
- カラーマップ: 発散型。0 = ほぼ背景色 (#0b0e14)、正 = 橙→黄白、負 = 青→水色。
  表示ゲインは u0 にほぼ反比例させる（目安 `gain ≈ 6/u0`）。256×2 段の LUT を事前計算。
- 障害物セルはグレー (#666)。
- **トレーサー粒子 ~4000 個**: 格子速度を双線形補間し、`速度 × SCALE × steps/frame` だけ移動。
  前フレーム位置から現在位置へ α≈0.35 の白い線分を引く（流脈っぽく見える）。
  右端に出た/障害物に入った粒子は x=1〜4、y 乱数で再投入。
- 描画は NX×NY の ImageData → `putImageData` → メイン canvas に拡大 `drawImage`（smoothing 有効）。

## UI

- 上部バー: 流速 u0 / 粘性（対数スライダー）/ 半径 / 形状（円・角柱・平板・三角）/ ステップ数 /
  粒子表示 ON/OFF / 流れリセット / 障害物リセット。右側に **Re と FPS** を常時表示。
- マウス: 左ドラッグで障害物を描く、Shift+ドラッグで消す。
  消したセルは平衡分布 (ρ=1, u=0) で埋め直す。上下壁の行と流入・流出列には描けない。

## 落とし穴

- **τ ≤ 0.5 で即発散**。粘性スライダーの下限で τ ≥ 0.51 を保証すること。
- ストリーミングの in-place 実装は不可。必ずダブルバッファ。
- 流入境界を毎ステップ上書きしないと、初期の圧力波が反射して戻ってくる。
- 平衡分布の係数 (3, 4.5, 1.5) の書き間違いが最頻バグ。`4.5(e·u)² = 0.5·(3(e·u))²` で共通化すると安全。
- ImageData はシミュ解像度で作って拡大描画する（フル解像度で per-pixel 計算しない）。
